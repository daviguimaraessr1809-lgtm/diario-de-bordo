Aprendi na primeira aula:
1. O GitHub é uma plataforma utilizada para armazenar, organizar e compartilhar projetos e códigos.
2. Os repositórios funcionam como pastas virtuais onde os arquivos de um projeto ficam armazenados.
3. O Git permite acompanhar as alterações feitas nos arquivos e recuperar versões anteriores de um projeto.
4. É possível trabalhar em equipe pelo GitHub, permitindo que diferentes pessoas contribuam para o mesmo projeto.
