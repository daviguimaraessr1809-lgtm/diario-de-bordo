# Diário de bordo
Este diário de bordo é meu diário de aprendizagem, no qual registrarei minhas experiências, descobertas, dificuldades e conhecimentos adquiridos ao longo das atividades. Ele representa uma forma de acompanhar minha evolução, refletir sobre o que aprendi e documentar cada etapa da minha jornada de aprendizado.
